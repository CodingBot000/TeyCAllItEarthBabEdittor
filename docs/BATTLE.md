## 1. 진입과 공간

[BattleScreen](../src/game/battle/BattleScreen.tsx)이 [createSideViewBattleSession](../src/game/battle/gameplay/sideViewBattleRules.ts)으로 전투 상태를 만들고, 공통 Editor 장면과 선택된 맵의 이미지 패키지를 [런타임](../src/game/battle/runtime/createBattleRuntime.ts)에 넘긴다.

- 모선·지상 유닛은 X축 중심으로 움직인다. 모선 논리 Z는 0이며 공중 전투기는 실제 X/Y/Z 좌표를 쓴다.
- 시작 X=0, 논리 고도=33, 화면 월드 Y=16.5. `combatToWorld`는 Y에서 16.5를 뺀다.
- 정상 모선 최대 속도 17, 가속·감속 17. 정지에서 최대 속도까지 약 1초다. 과거 `BALANCE.mothership.maxSpeed=8`은 측면 런타임 속도가 아니다.
- 카메라는 원근 FOV 35°, 기본 Y=5/Z=-92, X축 추적이다. 사용자 카메라 회전·줌 입력은 없다.
- 프로필의 지상 월드 경계는 -132~132지만 모선 이동 한계는 뷰포트 폭으로 계산한다. 두 경계는 동일하지 않다. 바깥 군중의 접근성에 영향을 준다. [SYS-018](GAPS.md#sys-018)
- 시뮬레이션은 `1/60초` 고정 스텝, HUD 스냅샷은 대략 초당 10회 갱신한다. 화면 프레임과 도메인 시간은 구분된다.

## 4. 흡수 대상 생성과 탐지

### 지역 생성

- 프로필당 기본 지역 5개, 목표 최소 간격 28. 초기 화면 근처와 좌우 외곽에 배치한다.
- seed는 캠페인 seed·도시·방문 횟수·임무 ID·프로필 ID/버전에 의해 결정되며 확정 임무에 저장한다.
- 양 끝의 2개 슬롯은 ORGANIC 방공호로 우선 배정한다. 나머지는 프로필 가중치로 종류를 선택한다.
- 일반 자원은 도시의 종류별 잔량 범위 안에서 생성한다. **방공호 예외와 런타임 군중은 이 제한을 완전히 지키지 않는다.** [SYS-003](GAPS.md#sys-003)
- `EMP_WINDOW` 대상은 살아 있는 연결 시설이 EMP로 정지한 동안만 흡수 가능하다.
- `PLASMA_OPENING`은 연결 시설이 파괴돼야 열린다. 반드시 플라즈마 막타일 필요는 없다.
- `FACILITY_DISABLED` 판정도 코드에 있지만 현행 2D 기본 템플릿은 사용하지 않는다.

### 자동 탐지와 대상 선택

자동 발견 거리: `24 + scanner-array 레벨×6 + 대상 반경`. 발견은 무료다. 가까운 흡수 버튼의 선택 범위는 `대상 반경 + beam-radius 레벨 + 2`이며, 그중 가장 가까운 대상을 고른다.

도메인 빔 시작/유지 거리 제한은 별도로 `22 + 대상 반경`이다. 버튼이 잡는 범위와 유지 거리가 다르다. 큰 광선 그래픽의 지면 폭은 판정 반경이 아니다.

화면 밖 안내는 남은 대상 중 화면 밖 후보를 우선하고, 거리순으로 고른다. 고가치 보상·달성 가능한 목표를 추천하는 AI와는 다르다.

## 6. 흡수 속도·에너지·열·화물

기본 화물 용량 35,000. 종류의 무게가 아니라 **흡수 단위 1당 화물 1**을 사용한다. DATA/RELIC도 고유 아이템 대신 자원 수치로 바뀐다.

```text
초당 흡수량 = 5000 × 대상 density × (1 + beam-capacity 레벨×0.2) / 3
보통 2D 대상 density: ORGANIC 1.08, 그 외 0.96, 외부 군중 1
실제 흡수량 = min(대상 잔량, 남은 화물, 위 속도×처리 시간)
흡수 중 에너지 소비 = 초당 100
흡수 환급 에너지 = 흡수 1000단위당 14 (최대 에너지까지만)
비흡수 중 에너지 재생 = 초당 35 + energy-core 레벨×4
```

빔 시작에는 에너지 10 이상이 필요하다. 흡수 중 일반 에너지 재생은 정지하며, 에너지가 부족한 마지막 스텝은 가능한 시간만 처리한다. `beamEnergyCostMultiplier`, 대상 `energyCostMultiplier`는 현 소비식에 사용되지 않는다. 빔 효율 업그레이드는 현재 열을 줄이는 효과만 있다.

열 증가:

```text
초당 열 = 14 × (1 - beam-efficiency 레벨×0.1) × 무게계수 × 누적흡수계수
무게계수 = 1 + clamp((weight-1)/23, 0, 1)×0.65
누적흡수계수 = 1 + clamp(해당 대상 누적흡수량/10000, 0, 1)×0.6
```

열은 0~100. 60부터 WARM, 80부터 CRITICAL, 100에서 OVERHEATED. 과열 시 빔을 중단하고 2초 회복한다. 비흡수·회복 중 열은 초당 50 감소한다. 피격 중 빔 사용 시 열 +25와 강제 중단이 발생한다.

중단 조건: 수동 중단, 피격, 과열, 에너지 부족, 대상 고갈/잠금, 범위 이탈, 화물 만재, 철수 시작. 측면 런타임에서는 이동 입력 자체가 즉시 빔을 끊거나 이동 속도를 절반으로 만드는 분기가 없다. 이동하다 유지 범위를 벗어나면 중단된다. 과거 자유 전술 모드의 이동 감속 값을 현재 기능으로 안내하지 않는다.

## 7. 직접 능력

세 중량 능력은 **셀 0개여도 사용 가능하며 셀을 차감하지 않는다.** 에너지 비용은 모두 400이다.

| 능력 | 판정 | 효과 |
| --- | --- | --- |
| EMP | 28 내 자동 선정 위치, 반경 18 | 시설·지상 방어군 8초 정지, 레벨당 지속 +20%. 범위 내 미사일 제거 |
| EMP 전투기 | 동일한 X/Z 반경 판정 | 적당 10% + 레벨×2%p의 결정적 확률, 성공 대상 최대 1+레벨. 같은 시간 정지 |
| 플라즈마 | 28 내 자동 선정 위치, 반경 4.5 | 시설·지상 방어군 220, 전투기 40 피해. 모두 `1+plasma-damage 레벨×0.15` 적용 |
| 플라즈마 부수 효과 | 대상 반경까지 포함해 흡수 대상 검사 | 잔량 12% 파괴, ORGANIC은 인명 손실 누적, 경보 +2 |
| 오버드라이브 | 별도 표적 없음 | 5초간 모선 피해 60% 감소. 이동 속도 증가나 자동 회피기동은 아님 |

EMP/플라즈마 자동 표적 우선순위: 발견된 잠긴 자원에 연결된 시설 → 지상 방어군 → 기타 생존 시설 → 전투기. 각 단계에서는 거리순, 사거리 밖은 제외한다. 화면에서 가장 가까운 유닛이 항상 우선인 것은 아니다.

전투기 이동·방공 거리에는 3D 좌표를 사용하지만 EMP·플라즈마 범위는 X/Z 거리로 판정한다. 화면 전체로 퍼지는 플라즈마 번개·EMP 왜곡은 추가 피해 범위가 아니다. 활성화 순간 규칙 피해와 수초간의 연출도 시간상 다르다.

전투기 흡수는 정지/공격 상태 판정 함수가 있어도 항상 거부된다. EMP로 정지시킨 전투기를 포획하는 기능은 없다.

## 8. 자동 아군 공격

| 무기 | 기본 수치 | 실제 대상·처리 |
| --- | --- | --- |
| 대공 레이저 | 3초마다 피해 10 | 가까운 살아 있는 전투기부터. 기본 1대, 업그레이드로 최대 4대. 별도 사거리·에너지 소비 없음 |

| 지상 자폭드론 | 시작 2.5초 후, 8.4초 간격, 4발 | 가장 가까운 지상 방어군/시설. 발당 18×프로필 ground 배율. 에너지·코어·병력 소비 없음 |

자폭드론의 기본 이동 속도 8.4, 거리 기반 지속 2~8초를 기준으로 각 발에 시차를 둔다. 활성 최대 20발. 표적이 움직이면 X를 추적하며, 이미 파괴되면 해당 발사체를 제거한다. 프로필의 `groundPressureMultiplier`는 적 방어군뿐 아니라 **아군 드론 피해에도** 적용된다.

포인트 디펜스는 업그레이드로 성공률 최대 90%, 시도 비용 최소 5, 동시 최대 4발. 타깃 수와 에너지가 허용하는 만큼 처리하고 성공 이벤트·실패 이벤트를 각각 시각화한다.

## 9. 지구 측 전투 시스템

### 경보와 공중 증원

시작 경보 `clamp(도시 alert×0.45 + 전역 위협×0.12, 0, 100)`.

초당 경보 `(0.25 + 흡수 중 0.15×빔경보보정×대상경보배율) × (1 + 활성 RADAR 수×0.2)`.

20/40/60/80/100을 처음 넘을 때 편대 생성. 기본 편대 4/5/5/6/6에 도시 방어·프로필 배율을 적용하고 생존 적 최대 20대까지 생성한다. AIRBASE가 파괴되면 60 이상 증원은 생략한다. EMP 정지 상태의 AIRBASE는 이 ‘파괴’ 조건을 만족하지 않는다.

전투기: 기본 체력 50, 기본 공격 24에 도시 방어 배율 적용. `ORBIT → ATTACK_PASS → RECOVER` 상태로 실제 3D 비행한다. 모선 안전 타원체 밖을 유지하고, 공격은 거리 30~52에서 유도탄으로 수행한다. 편대 반경·속도·공격 시차는 seed로 결정한다. 적탄 기본 수명 8초, 방공 공격·EMP·플라즈마로 대응한다.

### 지상 유닛과 시설

| 종류 | 현재 생성·역할 |
| --- | --- |
| SAM | Coastal/Desert 3개, River 2개. 기본 체력 350. 모선 상대 사격 위치를 찾으며 움직이고 2연발 미사일 발사 |
| RADAR | 1개, 체력 280. 경보 증가 가속, DATA의 EMP 잠금과 연결 |
| AIRBASE | 1개, 체력 500. 높은 경보 증원과 RELIC 개방·점령 조건에 연결 |
| POWER | 1개, 체력 420. RAID 추가 돌파 목표, Desert의 세 번째 노드. 별도 전력망 차단 시뮬레이션 없음 |
| GroundDefender | 3개. 지상 코호트를 사거리 안에서 공격. 전차/개틀링 이미지가 있어도 모선을 향한 대공포 AI가 아님 |
| RESEARCH | 타입·가중치 존재. 현재 2D 바이옴에는 시설을 생성하지 않음 |

SAM 이동 속도는 모선 최대의 70%=11.9. 사격 각도 20~40°, 차체 반폭 4와 경계 여유 0.5를 적용하고 화면·월드 교집합 안에 유효 사격 지점이 있어야 한다. 움직이는 중 사격하지 않는다. 기본 2연발 간격 0.3초이며 발사 직전마다 정지·방향·각도·EMP·표적을 재검사한다. 공간 컨텍스트가 없으면 측면 사격을 보류한다.

SAM 기본 탄속 `16×도시 방어배율`, 탄 피해 `(90 + 경보×0.25)×도시 방어배율`. 재장전은 `max(1.5, (4.5-경보/45)/(방어배율×프로필 공중배율))`. 공통 사격 위치 AI가 연결된 종류는 현재 SAM뿐이다. 차량 겹침 해소·목적지 점유 분산·독립 포탑 회전은 없다.

## 10. 코호트의 실제 행동

출격 전에 선택한 ASSAULT 코호트는 전투 1.25초 후 모선 아래 간격 2.8로 자동 배치된다. `/`를 누를 필요가 없다.

- 기본 이동 3.5, 공격 접근 거리 2.5.
- 공격 DPS `18 × 공격업그레이드배율 × 전력/100 × 응집력/100`.
- 가장 가까운 생존 지상 방어군·시설을 공격한다. 모두 처리한 뒤 점령 임무에서는 다른 코호트와 목표가 겹치지 않게 필수 노드를 선택한다.
- EMP로 정지한 GroundDefender에 대한 코호트 피해는 현재 코드에서 적용하지 않는다. 일반 시설 피해에는 이 예외가 없다.
- 탈출 시작 시 RAID 병력은 모선으로 후퇴한다. 점령 조건이 준비된 OCCUPATION 병력은 현장에 남는다.
- 기본 회수 반경 8, 회수 프로토콜 레벨당 +25%. 철수 채널은 3초이므로 멀리 있는 코호트의 귀환을 보장하지 않는다.
- 전력 0, 회수 불가, 실패 임무의 배치 코호트는 LOST. 회수 또는 주둔 후보는 경험치 +1이지만 경험치로 능력이 오르는 규칙은 없다.

거점 조건과 주둔 확정은 [캠페인](CAMPAIGN.md)에 있다. 자동 AI를 수동 RTS 명령 UI로 설명하지 않는다.

## 11. 모선 방어·철수·대파

실드가 피해를 먼저 받으며 넘친 피해가 선체에 적용된다. 피격 후 실드 재생 대기 4초, 이후 초당 12. 선체의 자연 재생·일반 수리 버튼은 없다.

75초가 지나면 철수를 시작할 수 있고 장소 조건 없이 3초를 채운다. 철수 중 빔은 중단되지만 전투 피해·다른 능력·자동 전투는 계속 진행된다. 피격 자체가 철수 진행을 초기화하지는 않으며 완료 전 대파하면 실패한다.

대파는 `MOTHERSHIP_DISABLED`로 확정한 뒤 약 5.8초 시퀀스를 보여 주고 결과로 이동한다. 4.35초까지 불길·연기·공중 폭발, 이후 지면 폭발·파편. 추락 중 카메라는 추락체를 따라 내려가지 않는다. 임무 포기는 추락을 기다리지 않고 결과를 처리한다.
