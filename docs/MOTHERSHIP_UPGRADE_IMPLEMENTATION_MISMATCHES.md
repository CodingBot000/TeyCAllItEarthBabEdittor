## UPG-001. 흡수 광선 에너지 비용 보정값 미사용

### 현재 구현

- 흡수 광선 발동 에너지 비용은 0이다.
- 흡수 중 대상에서 에너지를 회수한다.
- `beam-efficiency` 업그레이드는 광선 열 증가량을 낮춘다.
- `beamEnergyCostMultiplier`가 계산되지만 실제 에너지 소비 계산에서는 사용되지 않는다.

### 불일치

에너지 비용을 보정하는 전투 보정값이 존재하지만, 실제 광선은 에너지를 소비하지 않아 해당 값의 효과가 없다.

### 결정 필요

- 흡수 광선에 초당 에너지 비용을 추가하고 보정값을 연결할지 결정
- 에너지 비용을 계속 0으로 유지한다면 `beamEnergyCostMultiplier`를 제거할지 결정
- 에너지 회수와 에너지 소비를 동시에 사용할 경우 순 에너지 변화량 표시 방식 결정

### 완료 조건

- 기획 설명과 실제 에너지 증감 규칙이 일치
- 사용하지 않는 보정값이 남아 있지 않음
- 업그레이드 카드가 실제 효과만 설명

## UPG-002. 플라즈마 전투기 피해 미적용

### 현재 구현

플라즈마 범위 안의 전투기는 피해량 계산 없이 체력이 바로 0이 된다. `plasmaDamageMultiplier`는 시설과 지상 방어군 피해에만 적용된다.

### 확정 기획

- 전투기 즉시 파괴 처리를 일반 피해 계산으로 변경
- 전투기에도 `plasma-damage`의 `+15%/레벨` 보정 적용
- 플라즈마 반경 안의 모든 전투기를 피해 대상으로 처리
- 기본 전투기 피해량은 밸런스 검토 후 확정

### 완료 조건

- 전투기 체력에서 계산된 플라즈마 피해가 차감됨
- 업그레이드 레벨 0~3에서 전투기 피해가 각각 검증됨
- 고방어력 전투기가 항상 즉시 파괴되지 않음

## UPG-003. EMP 전투기 무력화 미지원

### 현재 구현

EMP는 시설과 지상 방어군의 `disabledUntil`을 갱신하고 범위 안의 미사일을 제거하지만 전투기에는 영향을 주지 않는다.

### 확정 기획

EMP 범위 안의 각 전투기에 독립적으로 확률을 판정한다. 성공한 대상 중 모선과 가까운 전투기부터 최대 대상 수까지 무력화한다.

| EMP 업그레이드 레벨 | 전투기당 무력화 확률 | 최대 무력화 대상 | 무력화 지속 시간 |
|---:|---:|---:|---:|
| 0 | 10% | 1대 | 8.0초 |
| 1 | 12% | 2대 | 9.6초 |
| 2 | 14% | 3대 | 11.2초 |
| 3 | 16% | 4대 | 12.8초 |

### 완료 조건

- 범위 밖 전투기는 판정하지 않음
- 전투기마다 독립 확률 판정
- 최대 대상 수를 초과하지 않음
- 성공한 전투기의 `disabledUntil`이 해당 레벨의 EMP 지속 시간만큼 증가
- 결정적 테스트를 위해 확률 판정에 전투 시드 사용

## UPG-004. 방공 레이저 업그레이드 연결 부재

### 현재 구현

- 기본 피해 10
- 기본 발사 간격 3초
- 가장 가까운 전투기 1대 자동 공격
- `airDefenseLaserIntervalMultiplier`는 항상 1로 고정

### 확정 기획

- `air-defense-damage`: 피해 +20%/레벨
- `air-defense-cycle`: 발사 간격 -10%/레벨
- `air-defense-multitarget`: 동시 타깃 +1대/레벨
- 다중 타깃은 모선과 가까운 전투기부터 선정

### 완료 조건

- 레벨별 피해와 발사 간격 적용
- 한 발사 주기에 서로 다른 전투기를 최대 4대까지 공격
- 이미 파괴된 전투기를 다음 타깃으로 중복 선정하지 않음
- 전투 이벤트와 VFX가 타깃 수만큼 생성됨

## UPG-005. 요격 레이저 업그레이드 연결 부재

### 현재 구현

- 기본 요격 성공률은 구현 패턴상 75%
- 기본 발사 간격 0.45초
- 기본 사거리 14
- 타깃당 에너지 8 사용
- 한 번에 미사일 1발만 선택

### 확정 기획

- `point-defense-accuracy`: 성공률 +5%p/레벨
- `point-defense-efficiency`: 타깃당 에너지 비용 -1/레벨
- `point-defense-multitarget`: 동시 타깃 +1발/레벨
- 다중 타깃은 모선과 가까운 미사일부터 선정
- 에너지는 실제 요격을 시도한 타깃 수만큼 각각 소모

### 완료 조건

- 레벨 0~3 성공률 75% / 80% / 85% / 90% 적용
- 레벨 0~3 타깃당 에너지 8 / 7 / 6 / 5 적용
- 레벨 0~3 최대 타깃 1 / 2 / 3 / 4발 적용
- 에너지가 부족할 때 가능한 타깃 수만큼만 요격
- 타깃별 요격 성공 여부와 VFX가 독립적으로 처리됨

## UPG-006. 회수 프로토콜 카드 설명 누락

### 현재 구현

`recovery-protocol`은 카드에 표시된 코호트 손실 감소와 실패 화물 회수 증가 외에 코호트 회수 반경도 레벨당 25% 증가시킨다.

### 결정 필요

- 회수 반경 증가를 정식 효과로 유지하고 카드 설명에 추가할지 결정
- 의도하지 않은 효과라면 전투 보정값에서 제거할지 결정

## UPG-007. 위협 예측 효과 범위

### 현재 구현

`threat-forecast`는 실제 경보 증가량을 낮추지 않는다. 목표 추천과 위험 예측에 표시되는 예상 경보만 낮춘다.

### 결정 필요

- 현재처럼 예측 정확도·예측 결과 보정 업그레이드로 유지
- 또는 실제 경보 압력 감소 업그레이드로 변경
- 카드 문구가 최종 동작을 정확히 설명하도록 수정
