> 이후 모선 업그레이드 기획을 추가·수정할 때 이 문서를 갱신한다.

## 1. 현재 구현 요약

현재 업그레이드 화면은 단순한 화면 목업이 아니라, 구매 결과가 캠페인 상태와 전투 계산에 연결된 실제 기능이다.

- 업그레이드 카드 총 20종
- 신규 기획 카드 6종. 현재 구현 완료 전까지 기존 20종과 구분해서 관리
- 모든 업그레이드 최대 3레벨
- 바이오매스, 합금, 정보 자원으로 구매
- 구매 시 `CampaignState.upgrades`에 레벨 저장
- 일부 업그레이드는 모선 능력치나 물류 수치를 즉시 갱신
- 나머지는 전투 시작 시 `deriveCombatModifiers()`를 통해 전투 상태에 적용
- 선행 조건, 장착 슬롯, 장비 교체, 환불 기능은 현재 없음
- 업그레이드 카드는 카테고리 필터 없이 전체 목록으로 표시

## 2. 현재 모선 무기 목록

### 2.1 직접 조작 또는 전투 명령으로 사용하는 무기

| 무기 | 코드 ID / 입력 | 현재 기능 | 기본 수치 | 업그레이드 지원 |
|---|---|---|---|---|
| 흡수 광선 | `beam` / `B` | 인구·차량·기계·데이터 등 흡수, 화물 확보, 흡수량에 따른 에너지 회수 | 사거리 22, 흡수 속도 5,000/s, 기본 열 증가 14/s, 과열 회복 2초 | 지원: 용량, 반경, 효율 |
| 플라즈마 | `plasma` / `P` | 지상 시설·방어군 공격, 시설 파괴, 주변 표적에 부수 피해 | 에너지 90, 과충전 셀 1, 재사용 대기 3.5초, 사거리 28, 반경 4.5, 시설 피해 220 | 지원: 피해. 전투기 피해 적용 기획 추가 |
| EMP 펄스 | `emp` / `E` | 시설·지상 방어군을 일정 시간 무력화하고 주변 미사일 제거 | 에너지 180, 과충전 셀 1, 재사용 대기 16초, 사거리 28, 반경 18, 지속 8초 | 지원: 지속 시간. 전투기 확률 무력화 기획 추가 |

### 2.2 자동 방어 무기

| 무기 | 현재 기능 | 기본 수치 | 업그레이드 지원 |
|---|---|---|---|
| 방공 레이저 | 가장 가까운 전투기를 자동 공격 | 3초 간격, 피해 10 | 신규 업그레이드 기획 작성. 현재 미구현 |
| 요격 레이저 | 모선에 접근하는 적 미사일을 자동 요격 | 0.45초 간격, 사거리 14, 발동 시 에너지 8 사용 | 신규 업그레이드 기획 작성. 현재 미구현 |

방공 레이저와 요격 레이저는 전투 중 자동으로 작동한다. 현재 업그레이드 화면에는 이 두 무기에 대응하는 카드가 없으며, 이 문서의 신규 카드 6종은 아직 기획 상태다.

|---|---|---|---|---|
| 오버드라이브 | `overdrive` / `S` | 일정 시간 받는 피해 감소 | 에너지 280, 과충전 셀 1, 재사용 대기 18초, 지속 5초, 피해 감소 60% | 별도 업그레이드 없음 |
| 스캔 | `scan` | 숨겨진 흡수 표적 탐지. SIDE_VIEW에서는 자동 스캔으로 대체 | 기본 스캔 범위 28, 에너지 110, 재사용 대기 10초 | 스캐너 배열 |

## 3. 업그레이드 화면이 제공하는 UI 기능

구현 위치: [`UpgradeScreen.tsx`](../src/game/presentation/screens/UpgradeScreen.tsx)

### 3.1 좌측 정보 영역

화면 진입 시 다음 정보를 표시한다.

- 바이오매스 보유량
- 합금 보유량
- 정보 보유량
- 코어 충전량 / 최대 코어 충전량
- 과충전 셀 최대 수용량
- 코호트 전환 수용량
- 투하 수용량 / 지휘 대역폭

### 3.2 업그레이드 카드

각 카드에는 다음 정보와 동작이 있다.

- 업그레이드 카테고리
- 현재 레벨을 나타내는 3개 레벨 핍
- 이름
- 단계별 효과 설명
- 다음 레벨의 비용
- `INSTALL` 버튼
- 최대 레벨 도달 시 `MAXED` 표시
- 자원 부족 시 구매 버튼 비활성화

카드 이미지는 현재 실제 모듈 아트가 아니라 공통 CSS 썸네일에 색상 변화를 적용하는 방식이다.

### 3.3 구매 처리

구매 흐름은 다음과 같다.

1. 현재 업그레이드 레벨 확인
2. 다음 단계 비용 계산
3. 자원 보유량 검증
4. 자원 차감
5. 업그레이드 레벨 증가
6. 모선 또는 물류 상태 즉시 갱신
7. 이후 전투에서 전투 보정값 적용

비용은 대부분 현재 레벨에 따라 `기본 비용 × (현재 레벨 + 1)` 형태로 증가한다. 업그레이드별로 바이오매스·합금·정보 조합은 다르다.

## 5. 신규 자동 방어 무기 업그레이드 기획

> 아래 6종은 신규 기획안이며 현재 업그레이드 화면과 전투 규칙에는 구현되어 있지 않다. 기존 규칙에 맞춰 모두 최대 3레벨로 설계한다.

### 5.1 방공 레이저 업그레이드

| 업그레이드 ID | 표시 이름 | 단계별 효과 | 최대 레벨 효과 | 구현 상태 |
|---|---|---|---|---|
| `air-defense-damage` | 방공 레이저 출력 | 전투기 피해 +20%/레벨 | 기본 피해 10 → 16 | 기획 |
| `air-defense-cycle` | 방공 레이저 가속기 | 발사 간격 -10%/레벨 | 기본 3초 → 2.1초 | 기획 |
| `air-defense-multitarget` | 방공 다중 추적 배열 | 동시 공격 가능한 전투기 +1대/레벨 | 기본 1대 → 최대 4대 | 기획 |

다중 타깃 발사 시 현재 모선과 가까운 전투기부터 우선한다. 한 번의 발사 주기에 최대 타깃 수만큼 서로 다른 전투기를 공격한다.

### 5.2 요격 레이저 업그레이드

| 업그레이드 ID | 표시 이름 | 단계별 효과 | 최대 레벨 효과 | 구현 상태 |
|---|---|---|---|---|
| `point-defense-accuracy` | 요격 레이저 정밀도 | 요격 성공률 +5%p/레벨 | 기본 75% → 90% | 기획 |
| `point-defense-efficiency` | 요격 레이저 효율 | 타깃당 에너지 비용 -1/레벨 | 기본 8 → 5 | 기획 |
| `point-defense-multitarget` | 요격 다중 추적 배열 | 동시 요격 가능한 미사일 +1발/레벨 | 기본 1발 → 최대 4발 | 기획 |

다중 요격 시 모선과 가장 가까운 미사일부터 우선한다. 에너지는 실제로 요격을 시도한 타깃 수만큼 타깃당 비용을 각각 소모하며, 에너지가 부족하면 가능한 수만큼만 요격한다.

### 5.3 플라즈마 전투기 피해 규칙

`plasma-damage` 업그레이드의 피해 보정을 전투기에도 적용한다.

- 전투기를 즉시 파괴하는 현재 처리를 피해 계산 방식으로 변경
- 시설·지상 방어군과 동일하게 `+15%/레벨` 피해 보정 적용
- 플라즈마 반경 안에 있는 모든 전투기가 피해 대상
- 최종 기본 전투기 피해량은 밸런스 검토 후 확정

### 5.4 EMP 전투기 무력화 규칙

EMP 범위 안의 전투기마다 독립적으로 무력화 확률을 판정한다. 성공한 전투기 중 모선과 가까운 순서대로 현재 레벨의 최대 대상 수까지만 무력화한다. 무력화 지속 시간은 해당 레벨의 EMP 지속 시간을 사용한다.

| EMP 업그레이드 레벨 | 전투기당 무력화 확률 | 한 번에 무력화 가능한 최대 전투기 | EMP 지속 시간 |
|---:|---:|---:|---:|
| 0 | 10% | 1대 | 8.0초 |
| 1 | 12% | 2대 | 9.6초 |
| 2 | 14% | 3대 | 11.2초 |
| 3 | 16% | 4대 | 12.8초 |
