# Ground Defense Weapon List

지구 측 지상군은 미래형 에너지 무기보다 현대 방공망의 형태와 운용 방식을 기본으로 한다. 무기의 성능과 전투 연출은 게임적으로 확장할 수 있지만, 외형은 실제 군용 차량·포탑·레이더·미사일 발사체계를 참고한다.

## Design Principles

- 현대 방공무기 기반의 차체, 포탑, 발사관, 레이더, 탄약 공급 구조를 유지한다.
- 네온 코어, 홀로그램 장치, 에너지 블레이드 같은 과장된 SF 외형은 사용하지 않는다.
- 강한 인상은 무기의 크기보다 포신 수, 탄약 공급량, 발사 빈도, 연기, 섬광, 추적 레이더 연출로 만든다.
- 각 유닛은 탐지, 추적, 요격, 지속 화력, 전자전 중 하나의 주 역할을 가진다.
- 크기, 세부 제원, 화면 점유율, 배치 수량은 별도 단계에서 결정한다.

## Core Weapon List

### 1. Mobile Surface-to-Air Missile Launcher

- 현대식 이동식 지대공 미사일 발사차량 기반
- 모선을 직접 추적하고 유도 미사일을 발사하는 단발 고위력 유닛
- 수직 발사관 또는 경사 발사관, 접이식 레이더, 유압식 전개 다리를 사용
- 게임 역할: 강한 순간 피해, 발사 전 조준 시간, 미사일 회피 유도
- 시각 연출: 발사관 개방, 점화 연기, 미사일 상승 궤적, 재장전 대기

### 2. Heavy Anti-Air Gatling / CIWS

- 현대식 근접방어체계와 대공포 포탑 기반
- 다연장 회전 포신으로 모선의 실드를 지속적으로 압박
- 별도 추적 레이더 또는 광학 조준기를 포탑에 결합
- 게임 역할: 지속 피해, 실드 압박, 짧은 사거리의 강한 탄막
- 시각 연출: 포신 회전, 조준 레이저, 예광탄, 포구 섬광, 과열 및 냉각

### 3. Twin-Barrel Airburst Autocannon

- 35~40mm급 쌍열 대공포와 근접 방공차량 기반
- 직접 명중보다 공중 폭발탄과 짧은 연사로 넓은 영역을 제압
- 게임 역할: 전투기·드론 요격, 모선 주변의 탄막 형성, 중간 지속 피해
- 시각 연출: 포탑 추적, 공중 폭발, 파편 구름, 짧은 포구 섬광

### 4. Multi-Cell SAM Battery

- 여러 발사관을 가진 장거리 방공 포대 기반
- 한 번에 여러 미사일을 순차 발사해 모선의 회피를 압박
- 이동식 발사차량, 지휘차량, 보조 레이더가 하나의 포대처럼 구성됨
- 게임 역할: 단계형 공격, 다중 미사일 패턴, 보스전 압박 강화
- 시각 연출: 발사관별 순차 점화, 서로 다른 궤적, 재장전 및 발사 준비 상태

### 5. Long-Range Heavy Anti-Air Cannon

- 대구경 대공포 또는 해안 방어포 형태를 기반으로 한 장거리 포대
- 미사일보다 느리지만 포탄 한 발의 피해가 큰 무기
- 게임 역할: 긴 조준과 충전 이후 큰 피해를 주는 위험 지점
- 시각 연출: 포신 상승, 조준 추적, 강한 반동, 포연, 긴 탄도 궤적
- 비고: 레일건이나 초현대식 무기 형태가 아니라 기존 대구경 포병의 확장으로 표현한다.

### 6. Radar and Fire-Control Vehicle

- 이동식 대공 레이더와 방공 지휘차량 기반
- 직접 공격하지 않고 주변 방공 무기의 탐지와 명중을 지원
- 회전식 접시 레이더, 접이식 마스트, 지휘 통신 장비를 사용
- 게임 역할: 주변 유닛의 명중률·조준 속도·탐지 범위 강화
- 시각 연출: 레이더 회전, 스캔선, 표적 고정 표시, 통신 신호

### 7. Electronic Warfare / Jammer Vehicle

- 군용 통신교란·레이더 교란 차량 기반
- 일반 군용 트럭 또는 장갑차에 패널 안테나와 접이식 안테나 마스트를 탑재
- 게임 역할: 모선의 조준 방해, 미사일 유도 지연, 드론 통제 방해
- 시각 연출: 낮은 밝기의 전파 펄스, 화면 노이즈, 조준선 흔들림, 통신 두절 표시
- 디자인 제한: 빛나는 에너지 코어 대신 안테나, 케이블, 냉각 장치, 발전기를 강조한다.

### 8. Decoy and Signature Emitter Vehicle

- 열원·레이더 반사체·연막을 사용하는 현대식 기만 장비 기반
- 모선의 공격을 가짜 목표로 유도하거나 지상 포대의 생존성을 높임
- 게임 역할: 미끼 생성, 공격 방향 전환, 짧은 시간 동안 방공 포대 보호
- 시각 연출: 연막, 열원 플레어, 가짜 레이더 신호, 가짜 표적 표시

## Support Assets

무기 자체는 아니지만 지상 방공망의 현대전 느낌을 강화하기 위해 다음 보조 차량과 소품을 함께 고려한다.

- 미사일·포탄 재장전 차량
- 레이더 지휘 차량
- 이동식 발전기와 냉각 장치
- 탄약 컨테이너와 케이블 릴
- 유압식 전개 다리와 포대 방호벽
- 정비 인력, 탄약 운반 인력, 통신 안테나
- 파괴된 포탑, 전복된 탄약차, 연소 중인 차량 잔해

## Suggested Initial Production Set

첫 제작 묶음은 다음 5종으로 시작한다.

1. Mobile Surface-to-Air Missile Launcher
2. Heavy Anti-Air Gatling / CIWS
3. Twin-Barrel Airburst Autocannon
4. Radar and Fire-Control Vehicle
5. Electronic Warfare / Jammer Vehicle

이 5종이면 직접 피해, 지속 피해, 영역 제압, 지원, 방해 역할을 모두 구성할 수 있다. Multi-Cell SAM Battery와 Long-Range Heavy Anti-Air Cannon은 이후 고난도 스테이지나 보스전용으로 확장한다.

## Size and Layout

크기, 포탑 높이, 포신 길이, 발사관 수, 화면 점유율, 레인별 배치 수량은 후속 작업에서 결정한다.
